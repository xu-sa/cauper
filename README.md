# cauper
ScreenCast&amp;controll your PC via LAN using Android

# project Structure 

this is a Repository containing three projects, each Folder stands for one of it.

# capureclt
the client app source code, provide building scripts for linux and android(A NDK is Required)

# capureser
the server app source code, provide building scripts for linux and windows(A cross complie development is required)

# capureandroid
the android application source code and UI designs, need a android NDK to build and also the lib file built from capureclt as JNI lib
